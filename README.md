# Suíte de Testes Automatizados - Doutor-IE (QA)

Projeto de automação de testes desenvolvido com **Playwright** para validação das funcionalidades do sistema Doutor-IE (Catálogo, Favoritos, Ordenação e Fluxo de Revisões).

## Pré-requisitos
Certifique-se de ter instalado em sua máquina:
* **Node.js** (versão 18 ou superior recomendada)
* A aplicação local do Doutor-IE rodando na porta `3000` (`http://localhost:3000`).

## Instalação

1. Clone o repositório ou abra a pasta do projeto no terminal.
2. Instale as dependências do projeto:
   ```bash
   npm install
